Notes on $D^b(\mathrm{Coh}\,X)$ and Fourier–Mukai kernels.
Not Hodge. Not Tate. Not Clay. Not a counterexample.

A kernel $\mathcal{E}\in D^b(X\times Y)$ is a complex on a product. It does not write $I(Z_i)$ from a Hodge class on a fourfold. The Kuznetsov component of a *cubic* fourfold is a K3 category; it does not attach to the locked sextic $V(F)\subset\mathbb{P}^5$.
