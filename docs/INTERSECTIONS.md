# Intersections of S on X

Author: Benjamin Stanley Frohman. Apache-2.0.
Status: Written geometry of (X, Π, S). Not a partner fourfold.

## Lattice already locked

h⁴ = deg X = 6.
h² · [Π] = 1 (a general linear P³ meets Π in a point).
Π² = 21.
[S] = h² − [Π].

## Pairings

$$
[S]\cdot h^2 = 6-1 = 5,
\qquad
[S]\cdot[\Pi] = 1-21 = -20,
\qquad
[S]^2 = 6-2+21 = 25.
$$

## Curve C = Π ∩ S

On L, t=0 cuts Π and R|_{t=0} = a x0^5 + b x1^5 + c x2^5.
So C ⊂ Π ≅ P² is the plane quintic

$$
C_{a,b,c}:\ a x_0^5 + b x_1^5 + c x_2^5 = 0.
$$

If abc ≠ 0 this is a smooth Fermat-type plane quintic, genus 6.

## Discriminant curve in the base

V(a^6+b^6+c^6) ⊂ P² is a smooth Fermat sextic, genus 10.

## Hodge numbers of S (classical quintic surface)

p_g=4, q=0, χ(O)=5, e=55, b2=53, h^{1,1}=45.

## Not Y

Bl_Π X has canonical class 2E, not O. Do not call the blowup a 4-CY partner.
