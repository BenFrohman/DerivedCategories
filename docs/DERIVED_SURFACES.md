## Written

On the locked host X = V(F):

- O_Π, the structure sheaf of the plane Π = V(x3,x4,x5)
- O_S, the structure sheaf of the residual quintic S_{a,b,c}

Class relation: [S] = h^2 - [Π] in H^4(X). Both classes are algebraic.

Sister-library surfaces (HODGE named_fourfolds), same rule:
P^4 plane, Klein Π/Π', Fermat Z1/Z2, Hassett extra plane.
Each is an object of D^b of its host. None is a miss.

## Unwritten

Y, E ∈ D^b(X × Y), Φ_E equivalence, Term A, Term B.
