## In hand

    X = V(F) subset P^5
    Pi = V(x3,x4,x5)
    L_{a,b,c} ≃ P^3 through Pi
    X ∩ L = Pi ∪ S_{a,b,c}
    [S] = h^2 - [Pi] in H^4(X)

Both [Pi] and [S] are algebraic. They span a rank-2 lattice with

    h^4 = 6,  h^2·[Pi] = 1,  Pi^2 = 21,
    [S]·h^2 = 5,  [S]·[Pi] = -20,  [S]^2 = 25.

## Family

Base: [a:b:c] in P^2 minus V(abc(a^6+b^6+c^6)).
Smooth fibre: quintic surface in L ≃ P^3.
K_S ≃ O_S(1), p_g = 4, q = 0, e(S) = 55, h^{1,1}(S) = 45.
C = Pi ∩ S is a plane quintic of genus 6.

A very general quintic surface in P^3 has Picard rank 1,
generated by O_S(1). That is Lefschetz (1,1) on S, not Hodge
on the fourfold X.

## What this does on X

[S] is a second algebraic (2,2)-class besides [Pi] and h^2,
but it is the difference h^2 - [Pi]. No new direction in
Hdg^2(X) is produced. CycleSection on this host still uses
the plane span. named_fourfolds stays a finite list.
